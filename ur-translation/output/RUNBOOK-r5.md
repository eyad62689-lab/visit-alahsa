6. حروف الأوردو لا العربية: ی U+06CC، ک U+06A9، ہ U+06C1، ے، ں، ھ للمهموسات فقط، ٹ ڈ ڑ. **أبداً** ي ك ة ه ى أ إ ۃ. الوقفة «۔»، الفاصلة «،»، الاستفهام «؟»، الاقتباس “…”. لا وقفة في آخر العناوين والتسميات والأزرار والشارات ولا في آخر قيمة خانة. المخاطبة **آپ** بالتعظيم.
7. النبرة: أوردية سياحية فصيحة سهلة (بی بی سی اردو، اردو نیوز)، لا ترجمة حرفية، لا دفتری اردو، لا تعريب مغالٍ («نخلستان» لا «واحہ»)، لا ميل سنسكريتي، لا حشو ترويجي.

## المخرج: ملف JSON واحد لكل مرحلة
```json
{ "batch": "<اسم الدفعة>", "stage": N,
  "strings": { "<كل مفاتيح pack.json بترتيبها>": "النص الأوردي" },
  "termbase_additions": [ { "en": "...", "ar": "...", "ur": "...", "gender": "مذکر|مؤنث", "plural": "...", "kind": "place|person|org|generic|brand|dish", "source": "...", "note": "..." } ],
  "notes": [ "تراكمية: انسخ ملاحظات المراحل قبلك ثم أضف ملاحظاتك مسبوقة بـ[sN]" ],
  "stage_specific": { } }
```
- المرحلة 1 (`ur-01.json`): الترجمة الأولى بكل المفاتيح. `stage_specific.divergences` — كل اختلاف واقعة بين en وar وكيف حُسم (العربية الفيصل).
- المرحلتان 2+3 معاً (`ur-02.json`, `stage: 23`): المحرر الأم ثم الموائم الثقافي في وكيل واحد (اقرأ دوري 02 و03). `stage_specific.changed` قائمة {key, before, after, why} لكل تعديل؛ **سياج الوقائع**: لا تضف واقعة.
- المرحلة 4 (`ur-04.json`): المقارن المرجعي + سياج الوقائع. `stage_specific.changed` و`stage_specific.fact_fence` (ما حُذف ومن أين جاء). كل حكم جديد يُكتب في `notes` بالشكل `[s4] Nxxx (عنوان): نص الحكم` ويُرقَّم من نطاق الدفعة في `pack.json → ids.s4` حصراً (الحاكم يبدأ من `ids.judge`). الأحكام تُحصر فيما تقرره لا أوسع (حارس آلي واسع يُلزم كل الدفعات اللاحقة).
- المرحلة 5 (`ur-05.json`): المدقق. `stage_specific.checklist` = البنود الأحد عشر من دورك + ما تسمّيه BRIEF، وكلٌّ PASS أو FIXED مع التفصيل، والبند الأول يحمل قائمة النقاط المحرفية الموجودة أو «none».
