Search-result description (◇) — "الاحساء کے پکوانوں کی سیر: الاحساء کے چاول، مندی، ہریس، ..." — "پکوانوں کی سیر" (a "tour" of dishes) is a slightly brochure-ish turn, but it is understandable, and the list itself is useful: it tells me straight away which eight dishes are on the page. `minor`. Something like "الاحساء کے روایتی پکوان: ..." would have worked.

2. Intro paragraph under "# الاحساء کے پکوان" — "الاحساء کے کھانوں کی بنیاد نخلستان کی نعمتوں پر ہے: الاحساء کے مقامی چاول، کھجور کا شیرہ، خشک لیموں اور دلی ہوئی گندم۔" — reads well and clearly. "دلی ہوئی گندم" and "خشک لیموں" are clear to me. "اپنائیت بھرے پکوان ... نسل در نسل دسترخوانوں پر چلے آ رہے ہیں" is warm and natural. No problem.

3. Section heading "## نخلستان کے قلب سے آٹھ پکوان" — "قلب" is bookish here; an ordinary Urdu writer would say "دل". The count (eight) matches the cards. `minor`. Suggest: "نخلستان کے دل سے آٹھ پکوان".

4. Dish "الاحساء کے چاول" — heading — The dish's name is exactly the same as the ingredient the intro just listed ("الاحساء کے مقامی چاول"). On first read I could not tell if this card was about a rice variety (the grain) or a cooked dish. Only the description ("اس میں الاحساء کے مقامی چاول گوشت یا مرغی ... کے ساتھ ... پکتے ہیں") made it clear it is a cooked rice dish, and that is folded when the page opens. The card does not give the dish a name I could ask for in a restaurant. `moderate`. If the dish has a local name, it is missing; otherwise something like "الاحساء کے چاول (پکوان)" would at least have separated it from the grain.

5. Dish "الاحساء کے چاول" — description — "مسالوں (خشک لیموں، دار چینی اور الائچی)" — the bracket is clear (it lists the spices), and "سرخی مائل بھورا" and "تقریبات میں اور مہمان نوازی کے دسترخوانوں پر" read naturally. This description is good: I know what is in it and when it is served.

6. Dish "مندی" — heading — "مندی" — in Urdu, "مندی" first reads as the ordinary word for a slump in the market (business going down), and it looks close to "منڈی" (market). Because I know mandi from Gulf restaurants I recovered fast, but the heading on its own gives no hint that this is a food name. The card label "مرکزی کھانا" helps. `moderate`. Nothing has to change in the spelling, but the first line of the description could make it obvious that this is a rice-and-meat dish (see 8).

7. Dish "مندی" — description, first sentence — "الاحساء میں مندی نامی پکوان کو پکانے سے بڑھ کر زمین کی تہ میں سنبھال کر رکھا جاتا ہے، جیسے راز سنبھال کر رکھے جاتے ہیں۔" — I read this three times. Literally it says the dish is "kept/preserved in the depth of the earth like secrets", "more than cooked". I could not tell if it means the food is cooked in a pit underground, or stored underground, or if this is just poetry. As someone deciding what to order, I came away not knowing how mandi is made. `serious`. A plain statement of the cooking method would have worked; the page as it stands does not say it clearly, so I cannot supply one.

8. Dish "مندی" — description vs photo — The photo description says "دہکتے تندور کے دہانے کے پاس مندی کا تھال" (a tray by the mouth of a glowing tandoor). The text says "زمین کی تہ میں" (in the depth of the earth) and then "مٹی کے تندور کی سانسیں". So is it a tandoor or a hole in the ground? The text and the image pull in different directions. Also, rice turns up for the first time in "چاولوں میں ... مہک بس جاتی ہے" without ever being told the dish is meat and rice; I only worked that out myself. `moderate`.

9. Dish "مندی" — description, last sentences — "گوشت گھنٹوں مٹی کے تندور کی سانسیں اپنے اندر جذب کرتا ہے" and "یہ پکوان ایک ایسے نخلستان کی داستان سناتا ہے جو سخاوت کو اس کا نام رکھنے سے پہلے ہی جانتا تھا۔" — grammatical, but this sounds translated. No Urdu writer says an oasis "knew generosity before giving it its name". It is brochure poetry that tells me nothing about the food. `moderate`. Dropping the last sentence would lose nothing.

10. Dish "ہریس" — description — "جب گندم اور گوشت گھنٹوں ایک دوسرے میں گھل مل کر ایک جان ہو جاتے ہیں تو ہریس جنم لیتا ہے۔" — flowery, but natural Urdu imagery ("ایک جان ہو جانا"), and it tells me what the dish is (wheat and meat cooked for hours, like our haleem). Fine.

11. Dish "ہریس" — description — "یہ الاحساء کی دعوتوں اور شادیوں میں سخاوت کا اولین پکوان ہے" — "سخاوت کا اولین پکوان" ("the foremost dish of generosity") sounds foreign; I understood that it is the main dish at feasts only after a second look. `minor`. Suggest: "یہ الاحساء کی دعوتوں اور شادیوں کا سب سے اہم پکوان ہے". The Ramadan clause "مدتوں سے رمضان کے دسترخوانوں کا ساتھی رہا ہے" reads fine.

12. Dish "مفلق" — photo description and description — "مفلق، یعنی کھجوروں کے ساتھ دلی ہوئی گندم" — helpful: the unfamiliar name is explained straight away. The description is clear about what it is made of (cracked wheat, spices, dried lime, dates and boiled eggs on top). Reads well.

13. Dish "مفلق" — description — "دلی ہوئی گندم (جریش)" — the bracketed "جریش" is an Arabic word that is not explained, and nowhere else on the page uses it. I guessed it is the local name for the same thing, but its purpose is not stated. `minor`. If it is meant as the name to ask for, something like "(جسے وہاں جریش کہتے ہیں)" would make that clear.

14. Dish "کھجور کے شیرے کے ساتھ بلالیط" — heading — "بلالیط" — an unfamiliar name with a "ط" ending that looks un-Urdu; from the heading alone I could not tell what it is. The photo description ("بلالیط کی سویاں") and the description ("سنہری سویاں") explain it is vermicelli, so I got there. `minor`.

15. Dish "کھجور کے شیرے کے ساتھ بلالیط" — photo description — "اور پاس ہی خاگینے کی کڑاہی" — the photo shows a pan of khagina (egg) beside the vermicelli, but the description never mentions egg. Is the egg part of the dish or just something else in the picture? This is left hanging. `minor`.

16. Dish "کھجور کے شیرے کے ساتھ بلالیط" — description — "زعفران اور الائچی سے مہکتی سنہری سویاں، جنہیں الاحساء کے انداز میں کھجور کے شیرے سے میٹھا کیا جاتا ہے۔" — clear. But the next sentence, "جو سرزمین کھجور کے درختوں کا دارالحکومت ہے، وہاں مٹھاس خود کھجور سے آتی ہے۔", is brochure-shouty and translated-sounding: "the capital of date palms" is not an Urdu way to put it, and the relative clause at the front made me lose the thread. `minor`.

Imagery like "گھی کا تاج پہناتے ہیں" is a bit ornate but readable. Good card overall.

18. Dish "کھجور کا عصیدہ" — photo description vs description — Photo: "جس کے بیچ میں کھجور کے شیرے سے بھرا گڑھا ہے". Text: "پھر اسے گھی کا تاج پہناتے ہیں". 19. Dish "کھجور کا عصیدہ" — description — "عصیدے کو صبر سے اس وقت تک چلاتے ہیں جب تک وہ گاڑھا ہو کر زعفران سے چمکنے نہ لگے۔" — saffron appears here for the first time, as if I had already been told it was in the dish; the ingredient list does not include it. Small stumble. `minor`.

20. Dish "ساگودانہ" — description — "چھوٹے چھوٹے ساگودانے آنچ پر گھلتے گھلتے ایک شفاف نگینہ بن جاتے ہیں" — the many grains turning into "a single gem" is pretty but odd, and "گھلتے" (dissolving) is not what sago does.
