## دورة الدفعة

1. اقرأ الملفات الخمسة كاملة — **العربية والإنجليزية معاً؛ العربية هي الفيصل**. كثير من
   «الإضافات» المزعومة موجود فيها، وبعض المعلومات سقط من الإنجليزية.
2. أضف المصطلحات الجديدة إلى termbase **قبل** استعمالها، بحقول en/ar/zh/note/source.
3. ترجمة ← تحرير ← موائمة ← مقارنة ← تدقيق (`proof.py` حتى PASS).
4. قراءة عمياء: نص صيني فقط، بلا مصدر وبلا ذكر أنها ترجمة.
5. حكّم بصدق. `fill.py` ثم `npm run build` (astro check صفر أخطاء شرط) ثم commit وpush.
