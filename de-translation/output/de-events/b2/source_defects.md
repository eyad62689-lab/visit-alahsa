# علل المصدر — de-events-2

- **ev.kafu-nights.season / ev.kafu-nights.time / ev.kafu-nights.span (Kafu Nights event fields, en/ar source)**: The source models this single Ramadan event's 'season', 'time' and 'duration' fields all around the one fact 'Ramadan': the duration field ('Extended Ramadan nights'/«ليالٍ رمضانية ممتدة») never states an actual length the way sibling events do ('A few days', 'Several weeks'), and season+time both reduce to 'Ramadan' ('The holy month of Ramadan' / 'During Ramadan'), reading as circular once translated side by side. This is a gap in the source content model, not a translation defect (blind-reader observations 8 and 10). (en, ar, and therefore every target language built from them (de, zh, ru))
- **ev.dates-festival.place (en "Al-Ahsa Municipality Fort" / ar «قلعة أمانة الأحساء»)**: Unlike the other three events, which are held at named, well-documented historic landmarks, the source gives this venue no proper name or descriptive attribute beyond 'the municipality's fort'. Stage 4's dated web search (2026-09-19) found no German, English or authoritative source naming the building itself, so it remains a literal, faithful but under-specified descriptive translation, and a termbase 'pending' entry (blind-reader observation 11). (en, ar, and therefore every target language built from them (de, zh, ru))
