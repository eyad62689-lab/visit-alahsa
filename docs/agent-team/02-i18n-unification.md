# توحيد i18n — تشخيص وتقدير كلفة

**التاريخ:** 2026-09-03 · **الحالة:** تشخيص. **لم يُنفَّذ شيء** — لا سطر كود ولا إعداد.
**نطاق القياس:** فرع `feature/german-integration` (أحدث حالة تشمل الألمانية)، بأوامر `git grep` على `src/` — الأرقام أدناه مقيسة لا مقدَّرة.

---

## ١. الحقيقة التي تسبق كل نقاش: Astro i18n **غير مستعمل إطلاقاً**

```
git grep "astro:i18n|currentLocale|preferredLocale|getRelativeLocaleUrl" -- src
→ لا استعمال إطلاقاً
```

`astro.config.mjs` يعلن `i18n: { defaultLocale: 'ar', locales: ['ar','en'], routing: { prefixDefaultLocale: false } }` — **ولا سطر واحد في المشروع يستهلك هذا الإعلان.**

نظام اللغة كله مبنيّ يدوياً في `src/i18n/utils.ts`، ومصدر الحقيقة فيه **مقطع المسار الأول** لا Astro:

```ts
export function getLangFromUrl(url: URL): Lang {
  const [, seg] = url.pathname.split('/');
  return seg === 'en' ? 'en' : seg === 'zh' ? 'zh' : seg === 'de' ? 'de' : 'ar';
}
```

**النتيجة المباشرة:** الصينية والألمانية ليستا «خارج النظام» كما بدا في المسح الأول — لا يوجد نظام تنتميان إليه أصلاً. `locales: ['ar','en']` **إعلان ميّت**، وليس مصدر أي سلوك.

---

## ٢. ما الذي يتطلبه إدخال `zh` و`de` في `astro.config.mjs` رسمياً

### ٢.١ التغيير النصّي: سطر واحد

```diff
- locales: ['ar', 'en'],
+ locales: ['ar', 'en', 'zh', 'de'],
```

### ٢.٢ ما الذي يتغيّر فعلاً في السلوك

| ما يتغيّر | الأثر على الموقع اليوم |
|---|---|
| `Astro.currentLocale` يبدأ يعرف zh/de | **صفر** — لا مستهلك |
| دوال `astro:i18n` تشمل اللغتين | **صفر** — لا مستهلك |
| توليد المسارات | **صفر** — الصفحات موضوعة يدوياً في `src/pages/zh/` و`src/pages/de/`، و`prefixDefaultLocale: false` لا يولّد شيئاً |
| `i18n.fallback` | **غير مضبوط** — لو ضُبط لاحقاً فسيولّد صفحات/تحويلات تلقائية لكل لغة ناقصة، وهذا **يناقض بوابتَي `title_zh`/`title_de`** اللتين تمنعان عمداً ظهور صفحة غير مترجمة |

**الخلاصة:** إدخال اللغتين في الإعداد **تغييرٌ توثيقي لا وظيفي**. كلفته سطر، وعائده صفر اليوم — وقيمته الوحيدة أنه يمنع مطوّراً قادماً من الاستنتاج الخاطئ بأن الموقع ثنائي اللغة.

### ٢.٣ الخطر الحقيقي — وهو خطر مؤجَّل لا حالي

`i18n.fallback` و`routing.fallbackType: 'redirect'` هما الفخ: أي ضبط لهما لاحقاً يولّد لكل صفحة zh/de غير موجودة **تحويلاً أو نسخة من الإنجليزية**، فينهار العقد المكتوب في `content.config.ts`:

> «بوابة توليد صفحة المعلم الصينية هي حقل `title_zh` … فلا يقود المبدّل إلى 404»

البوابة تمنع **الصفحة الرقيقة**؛ و`fallback` يعيدها من الباب الخلفي — وهذه المرة بمحتوى إنجليزي تحت مسار صيني، وهو أسوأ من 404 لدى محركات البحث (محتوى مكرّر بلغة خاطئة).

> **إن أُدخلت اللغتان، يجب أن يُكتب بجانب السطر تعليق يحرّم `fallback` صراحةً** — أو يُضاف فحص `C15` يفشل عند وجود `i18n.fallback` في الإعداد. الفحص أقوى: التعليق يُقرأ والفحص يُنفَّذ.

## ٤. حجة الاختيار — **النمطان يبقيان، والتوحيد خطأ**

هذه الوثيقة طُلب منها «توحيد آلية الترجمة على نمط واحد مع حجة الاختيار». الحجة تقود إلى نتيجة معاكسة، وهذه هي:

### لماذا لا يُوحَّد على نمط الحقول (أ)

مقال المدونة متن طويل (‏1500–3000 كلمة). وضعه في حقل ترويسة يعني:

- **سلسلة YAML عملاقة** بلا Markdown حقيقي — لا عناوين فرعية ولا جداول ولا قوائم، وهي بنية أساسية في مقالات «48 ساعة» و«يوم واحد».
- ضياع `pubDate`/`updatedDate` المستقلين لكل لغة (النسخة الإنجليزية قد تُحدَّث وحدها).
- ملف واحد بـ8 آلاف كلمة بأربع لغات — يستحيل مراجعته في PR.

هذا هو بالضبط التعليل المكتوب أصلاً في `../../src/content.config.ts`: «المقال طويل فلا يصلح نمط حقول `_en`». **القرار قائم ومعلَّل، ولا معطى جديداً ينقضه.**

### لماذا لا يُوحَّد على نمط الملفات الموازية (ب)

تحويل 89 ملف محتوى إلى 89 × 4 = **356 ملفاً** يعني:

- **403 موضع `_zh` و520 موضع `_en`** تُفكَّك وتُعاد كتابتها — أضخم عملية نقل في تاريخ المشروع، بلا أي مكسب للزائر.
- **انهيار خطَّي الترجمة**: `zh-translation` و`de-translation` وسكربتات `apply.mjs` كلها تكتب حقولاً داخل ملف واحد. التحويل يعني إعادة كتابة المهارتين وموجّهاتهما السبعة والسبعة.
- **فقدان الضمانة البنيوية**: نموذج `dining`/`stay` يُلزم `name_en` و`blurb_en` (غير اختياريين) فيستحيل ملف بلا إنجليزية. الملفات المنفصلة تجعل النقص **ممكناً وصامتاً**.
- **بوابتا `title_zh`/`title_de` تفقدان معناهما**: البوابة اليوم «حقل موجود في الملف» — تصير «ملف موجود في مجلد»، وهي أضعف (ملف فارغ يمرّ).

### القاعدة الصحيحة بدل التوحيد

النمطان ليسا تناقضاً بل **قاعدة واحدة مطبَّقة على حالتين**:

> **الحقول للمحتوى المهيكل القصير · الملفات المتوازية للمتن الطويل الحر.**

**المقترح الوحيد هنا: كتابة هذه القاعدة في `../../CLAUDE.md`** — سطر واحد يقطع إعادة فتح السؤال في كل جلسة. لا نقل ولا إعادة هيكلة.

## ٥. الفجوة الحقيقية التي كشفها القياس

التوحيد ليس المشكلة. المشكلة أن **`blog` لا يقبل zh/de أصلاً**:

```ts
lang: z.enum(['ar', 'en']),   // src/content.config.ts
```

المدونة **صفر% بالصينية والألمانية**، وليست ناقصة الترجمة فقط بل **مستحيلة الترجمة بنيوياً** — البناء يرفض `lang: 'zh'`. أي وكيل ترجمة يُكلَّف بالمدونة سيصطدم بهذا قبل أول سطر.

**حجم الإصلاح — مقيس:**

| البند | التغيير |
|---|---|
| `content.config.ts` | `z.enum(['ar','en','zh','de'])` — سطر واحد |
| `src/pages/zh/blog/[slug].astro` | ملف جديد (النظير الإنجليزي قالب جاهز) |
| `src/pages/de/blog/[slug].astro` | ملف جديد |
| `BlogIndexView.astro` | إزالة `hrefLang={zh ? 'en' : undefined}` (التراجع الحالي) |
| `sitemap.xml.ts` | اقتران أزواج `key` يمتد إلى zh/de |
| `Seo.astro` | يعمل كما هو (‏`alt.zh`/`alt.de` اختياريان أصلاً) |
| **الإجمالي** | **~6 ملفات** — لا 89 |

وهذا يفتح المدونة لخطَّي الترجمة بلا أي نقل بنيوي.

## ٦. المخاطر على الروابط القائمة وSEO

| الخطر | الاحتمال | لماذا |
|---|---|---|
| **تغيّر روابط قائمة** | **منعدم** — لأي خيار في هذه الوثيقة | لا مقترح يمسّ `slug_ar`/`slug_en`، والروابط تُبنى من `lib/routes.ts` وحده |
| **`i18n.fallback` يولّد محتوى مكرراً** | **مرتفع إن ضُبط** | ينتج إنجليزيةً تحت `/zh/` — محتوى مكرر بلغة معلَنة خاطئة، أسوأ من 404 |
| **hreflang يشير إلى صفحة غير موجودة** | **منعدم اليوم** | `Seo.astro:36-37` يُدرج `zh`/`de` فقط حين توجد نسخة فعلية — والتعليق في الملف يوثّق القصد |
| **`x-default` يشير للعربية** | قائم بالتصميم | `Seo.astro:38` — قرار صحيح (العربية هي الجذر) لكنه يستحق مراجعة إن صارت الإنجليزية أكثر زواراً |
| **انفجار حجم sitemap** | متوسط عند اكتمال de | 296 رابطاً الآن؛ اكتمال الألمانية يضيف ~140 |
| **`lang: 'zh'` في المدونة** | **الخطر الحقيقي** | كل جهد ترجمة للمدونة يصطدم بالمخطط ويتوقف |

**ما لا خطر فيه إطلاقاً:** إعلان اللغتين في `astro.config.mjs`. لا مستهلك له فلا أثر — إيجاباً أو سلباً.
