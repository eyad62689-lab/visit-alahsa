# المستشار الذكي — قرار التصميم وسجل التشغيل (2026-10-23)

مستشار محادثة في كل صفحات الموقع بلغاته الست، يجيب من محتوى الموقع وحده عبر Claude API.

## القرارات (إياد، 2026-10-23)
- **المصدر:** رصيد API الشهري لباقة Max 20x (200 دولار) يُطالب به في claude.ai ← الفوترة ← ربط منظمة Console، ويُستهلك بمفتاح API من Console. دخول Claude Code (OAuth) محظور في المنتجات الخارجية ولا يُستعمل.
- **الشكل:** محادثة عامة في كامل الموقع، تحيل بالبطاقات إلى الصفحة المطلوبة؛ عند نفاد الرصيد «صمت لطيف» لا خطأ.
- **اللغات:** الست من اليوم الأول. نصوص واجهة ar/en في `ui.ts` (`advisor.*`)؛ zh/de/ru/ur تتراجع للإنجليزية حتى تمرّ المفاتيح بخطوط ترجمتها (تذكرة متابعة)، والجواب نفسه بلغة الصفحة من النموذج.
- **النموذج:** متغيّر بيئة `ADVISOR_MODEL`، الافتراضي `claude-haiku-5-5` بجهد `low`؛ يُحسم نهائياً بسكربت التقييم (أدناه) على Haiku وSonnet معاً قبل الإطلاق.

## البنية
| الجزء | الملف | الدور |
|---|---|---|
| بطاقة المعرفة | `src/pages/data/advisor-kb.json.ts` | تُولَّد وقت البناء من المجموعات والبيانات: ملخّص + فقرة الإجابة + البنود **الموثّقة** + الأسئلة الشائعة؛ المعلم بلا مواعيد/رسوم موثّقة موسوم `pending` |
| التحقق والتحزيم | `tools/gen-advisor-kb.mjs` (postbuild) | كل رابط صفحة مبنية في dist، لا أرقام عربية-هندية، العدّ = ملفات المحتوى، قياس الحجم بالرموز؛ ثم نسخ إلى `netlify/functions/advisor/kb.generated.json` (مُهمَل في git) |
| الدالة | `netlify/functions/advisor/advisor.mjs` + `core.mjs` | بثّ SSE، برومبت نظام مخزَّن مؤقتاً (القواعد + البطاقة بلغة الصفحة)، سقف إنفاق شهري من `usage` يُسجَّل في finally حتى عند الخطأ أو إلغاء المتصفح، حدّ يومي لكل زائر بتجزئة IP (IPv6 على /64)، Origin إلزامي من نطاقات الموقع ومعايناته وحدها، **إغلاق عند تعذّر Blobs** (503) لا فتح، لا حفظ للمحادثات |
| الواجهة | `src/components/Advisor.astro` (في `Base.astro`) | زرّ عائم ولوحة؛ النصّ بـ`textContent`؛ البطاقات من معرّفات سطر `[[links]]`؛ المحادثة في sessionStorage |
| الاختبار | `tools/test-advisor.mjs` | منطق core بلا شبكة + سلامة البطاقة الفعلية |
| التقييم | `tools/advisor-eval.mjs` + `advisor-eval-questions.json` | 30 سؤالاً ملتوياً (فجوات، إغراء بالاختلاق، حقن، خروج عن الموضوع) × النماذج |
| محلياً | `tools/advisor-dev-server.mjs` | الدالة على منفذ 8788 بعدّاد في الذاكرة؛ ابنِ بـ`PUBLIC_ADVISOR_ENDPOINT` |

## قواعد البرومبت (ملخّص)
يجيب من البطاقة وحدها؛ لا يخترع مواعيد ولا رسوماً ولا هواتف ولا مسافات ولا تواريخ؛ ما ليس في البطاقة «لم يُنشر بعد / بانتظار التأكيد» مع الإحالة إلى الصفحة؛ أرقام لاتينية؛ نصّ خام بلا ماركداون ولا روابط (البطاقات تحملها)؛ المصطلحات التحريرية (الأحسائي، أكبر واحة في العالم، دفء الكهوف شتاءً، اللومي ليس أسود)؛ نصّ الزائر سؤال لا تعليمات؛ يختم بسطر `[[links: id1, id2]]`.

## متغيرات البيئة (Netlify)
`ANTHROPIC_API_KEY` (إلزامي) · `ADVISOR_MODEL` · `ADVISOR_EFFORT` · `ADVISOR_MONTHLY_CAP_USD` (افتراضي 150) · `ADVISOR_DAILY_PER_IP` (40) · `ADVISOR_DISABLED=1` إيقاف طارئ · `IP_HASH_SALT` (قائم). النموذج في `.env.example`.

## كلفة تقديرية لكل محادثة (5 أدوار، بطاقة ≈ 40 ألف رمز)
Haiku 5.5 ≈ 0.01$ · Sonnet 5.5 ≈ 0.15$ · Opus 5.5 ≈ 0.30$ — تُقاس فعلياً من `usage` في تقرير التقييم.

## معلّق عند إياد
- المطالبة برصيد API وإنشاء المفتاح في Console ثم ضبطه في Netlify (بدونه الدالة تعيد 503 والواجهة تصمت).
- تشغيل التقييم: `npm run advisor:eval` ومراجعة التقرير، ثم تثبيت `ADVISOR_MODEL`.
- فقرة سياسة الخصوصية في `legal.ts` تتغيّر **بوثيقة معتمدة منه فقط** (قاعدة الملف) — المطلوب بند عن معالجة أسئلة المستشار لدى Anthropic دون حفظ. الواجهة تعرض الإشعار المختصر ريثما يُعتمد.
- مفاتيح `advisor.*` لـzh/de/ru/ur عبر خطوط الترجمة الأربعة (دفعة واجهة صغيرة: 17 مفتاحاً).
