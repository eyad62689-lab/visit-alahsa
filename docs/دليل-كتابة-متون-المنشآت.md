# دليل كتابة متون صفحات المنشآت

> الغرض: تحويل نصّك إلى صفحة منشورة بلا وسيط. تكتب المتن في ملف المنشأة،
> تدفع، فتُولَّد الصفحة وتدخل sitemap والبصمات تلقائياً.
> العتبة وحججها في [قرار بنية صفحات المنشآت](قرار-بنية-صفحات-المنشآت.md).

---

## أين تكتب

كل منشأة ملفٌ واحد في `astro-site/src/content/dining/`. موضعان فقط تحرّرهما:

```markdown
body_en: "النص الإنجليزي هنا — سطر واحد بين علامتَي اقتباس"
---

النص العربي هنا، بعد سطر `---` الأخير. فقرات عادية، وسطر فارغ بين الفقرة والأخرى.
```

بقية الحقول مضبوطة ولا تُمَس (الاسم والموقع والصورة ورابط الخرائط).

## العتبة — يرفضها البناء إن لم تُستوفَ

| الشرط | القيمة |
|---|---|
| المتن العربي | **80 كلمة فأكثر** |
| المتن الإنجليزي | **100 كلمة فأكثر** |
| ألّا يكون المتن نسخةً من `blurb` | شرط قاطع |

لغةٌ عبرت والأخرى لم تعبر ⇒ تُنشر صفحة اللغة العابرة وحدها. فتستطيع البدء
بالعربية وحدها إن شئت.

## ما لا يُكتب (قاعدة «لا تُختلق معلومة»)

- **أوقات العمل والتقييم والحالة** — تُجلب من خرائط قوقل تلقائياً وتُعرض على
  الصفحة. كتابتها في المتن تجعلها تتقادم بلا إصلاح.
- **الأسعار** — لا مصدر موثوق، ولا تُعرض في أي موضع.
- **أحكام الجودة** («الأفضل»، «الأشهر»، «الألذّ») — ادعاء غير موثّق.
- **أصناف بعينها** ما لم تكن متأكداً منها اليوم؛ القوائم تتغير.
- **«أقسام عوائل»** — وسمها التدقيق السابق ادعاءً غير موثّق.

## ما يُكتب — خمسة عناصر تكفي الثمانين

1. **أين هو بالضبط**: الحي، وأقرب معلم أو شارع يعرفه الناس.
2. **ما الذي يميّز المكان بصرياً**: المبنى، الجلسة، الفناء، الطراز.
3. **متى يُقصد**: فطور؟ سهرة؟ بعد زيارة القيصرية؟ (وصف عادة لا موعد.)
4. **قصة أو أصل**: متى فُتح، ما معنى الاسم، لمن يعود — إن كنت تعرفه.
5. **كيف يصل إليه الزائر**: من أين، وكم يبعد تقريباً.

العنصران الرابع والخامس هما اللذان يصنعان الفرق: لا يملكهما تريب أدفايزر ولا
إنستغرام، وهما ما يجعل الصفحة تستحق الفهرسة.

## بعد الكتابة

```bash
cd astro-site && npm run build
```

الفحص `C11` يخبرك كم منشأة عبرت العتبة، ويُفشل البناء على متنٍ ناقص —
فلا تُنشر صفحة رقيقة بالخطأ.
