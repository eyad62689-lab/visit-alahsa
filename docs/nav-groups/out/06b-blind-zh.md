# 中文读者盲读笔记：导航（06b）

- **"探索绿洲"（菜单按钮 / 分区标题）**：自然，像旅游网站的栏目名，有诗意但不晦涩。看得出下面是游玩内容，开启后的"景点 | 路线 | 活动 | 传统集市、公园与农场"也印证了这一点。没有问题。
- **"景点"**：地道、清楚，无异议。
- **"路线"**：地道。单看有点宽泛（线路？交通路线？），但与"景点""活动"并列，能理解为游览线路。可接受。
- **"活动"**：自然。同级里它和"景点"并列，读者会猜是节庆/活动日程，可以接受。
- **"传统集市、公园与农场"**：意思清楚，但是菜单里最长、最不像菜单标签的一项：三个名词用顿号和"与"串起来，像一句说明而不是栏目名；手机上可能折行。同时"传统"只修饰集市还是三者都修饰，略有歧义（传统公园？）。建议缩短，例如"集市、公园与农场"，或"集市与田园"（视内容而定）。
- **"美食与购物"（菜单按钮 / 分区标题）**：自然，中文网站常见写法。但内容里有"餐厅与咖啡馆""网店"，分区名没有概括出"绿洲水果"和"网店"的关系，读者能理解（吃的+买的），可接受。
- **"哈萨美食"**：作为栏目名自然。但"哈萨"是地名音译，不熟悉的读者可能把它当成"哈萨克"的缩写，误以为是哈萨克斯坦美食；站名"哈萨旅游指南"已出现，缓解了一些，但在菜单里孤立看仍有一点歧义。是否可以在页面其他处保证"哈萨=本地区"的认知（如品牌名统一）。
- **"餐厅与咖啡馆"**：地道清楚，无问题。与"哈萨美食"的区别（前者像菜品介绍，后者像店家名录）能猜到，但不是一目了然。
- **"绿洲水果"**：略有歧义：是介绍水果（椰枣之类）的文章，还是买水果的地方？放在"美食与购物"下读起来偏向"特产介绍"。可接受，不必改；若是内容介绍页，"绿洲特产水果"更直白，但并非必须。
- **"网店"**：中文里"网店"通常指某个具体的网上商店，作为栏目名略显突兀，读者不确定是"本站的网上商店"还是"推荐的网店名单"。若是推荐名单，建议"网购推荐"或"线上商店"；若是本站商店，"在线商店"更清楚。
- **"住宿"**：自然、标准，无问题。
- **"地图"**：自然，无问题。注意：电脑版它是顶层独立链接，手机版却被放进"探索绿洲"分区里，两端归类不一致，中文读者无感，但属于结构不统一（不是措辞问题）。
- **"我的收藏"（图标链接）**：地道，中文 App/网站的标准说法。无问题。
- **"行程规划"（金色按钮）**：自然、地道，一眼是行动按钮；读者会期待"帮我排行程的工具"。无问题。
- **"出行指南"（仅手机版分区标题）**：这是三个分区标题里最成问题的一个。1) 它下面只有"住宿"和"我的收藏"，而"出行指南"在中文里通常期待"交通、签证、天气、实用信息、注意事项"，读者点开看到"住宿"会觉得名不副实；2) "我的收藏"是个人功能，不是"指南"内容，放在这里更奇怪；3) 与金色按钮"行程规划"、以及网站名"哈萨旅游指南"语义太近（都含"指南/规划"），容易混淆：标题和按钮在手机菜单里相邻出现，读者可能以为"出行指南"也是个工具/可点按钮。建议改成更贴切的"住宿与收藏"、"行前准备"（若会加入签证、交通等内容）或"实用信息"；若只有住宿，直接把"住宿"提升为顶层链接最干净。
- **分区标题与金色按钮是否易混**：三个标题里只有"出行指南"和"行程规划"在字面和意义上接近（出行/行程）；"探索绿洲""美食与购物"不会混淆。标题在视觉上若不可点（无箭头、非金色）则可区分，但文字层面建议拉开距离，见上条。
- **底部栏"语言： 中文（简体）"**：自然、清楚，中文网站常见。"（简体）"标注得当，无问题。
- **底部栏"切换 ⌄"**：问题较大。1) 单独的"切换"没有宾语，读者要联系同一行的"语言"才知道切换什么，且它与"语言： 中文（简体）"是分开的两个控件，视觉上容易被当成装饰或另一个功能（切换账号？切换货币？）；2) "⌄"是下拉箭头，与"切换"并用有点重复，"点击后展开语言列表"的提示靠箭头而非文字；3) 中文网站语言切换通常写"切换语言"或直接让整行可点（"中文（简体） ⌄"）。建议将按钮写成"切换语言 ⌄"，或把"语言： 中文（简体）"本身做成可点的下拉；至少改为"更改"/"更换语言"之一，且让按钮自带宾语。
- **整体印象**：用词基本是母语水平的网站菜单中文，没有翻译腔。需要处理的有三处：1) "出行指南"名不副实且与"行程规划"相近；2) 底部"切换"缺宾语；3) "传统集市、公园与农场"过长且"传统"的范围含糊。其余（"网店""哈萨美食"）属于小幅歧义，可视情况微调。
