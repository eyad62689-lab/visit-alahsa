# Blind read: terrain-map intro (zh)

## 1) What the page offers and what to do
This is a 3D terrain map of the oasis (mountains, date palm groves, dunes to the east) with every attraction marked on it, plus a list of attractions below the map, grouped by category (e.g. 历史古迹). To make a place appear on the map, I press the small icon button next to the name in the list; its tooltip says "在地图上查看" (view on map). To open a place's own page, I press the name itself. Yes, it is clear which element does which: button beside the name = show on map, the name = open the page. The only slight gap is that the icon button has no visible text, so I rely on the tooltip (and on the intro line) to know what it does; on a phone with no hover I would only learn it from the intro sentence.

## 2) Stumbles
1. "卡拉山" — I did not immediately recognize this as a mountain I know. It reads as a transliteration (Qarah / Gara), and as a non-local I would not know it is a famous site; it is understandable only as "a mountain named Kala/Kara". Minor.
2. "椰枣林" — I first read it as "coconut-date grove", because 椰 normally means coconut. It is understandable as "date palm grove" (more common in mainland Chinese: 枣椰树 / 椰枣树), and the word 椰枣 is in fact used, so it is acceptable, but a moment of hesitation.
3. "东边的沙丘" — "the dunes on the east side"; fine, but "东边" is slightly vague (east of what?). Very minor.
4. "游览指南地形图" — the title is a bit stacked/nominal: "tour guide terrain map". I first wondered whether it is a map of a guide. It parses fine on second look; slightly stiff but not wrong.
5. "每一处景点都标注在图上" — natural, but "每一处" plus "都" feels a touch like marketing copy. Not a real problem.

## 3) Readability of the two intro lines
88/100 — the instruction line (按钮 = 在地图上查看, 名称 = 打开页面) is clear and natural; the description line is slightly brochure-like and "卡拉山" / "椰枣" cause a brief pause.
