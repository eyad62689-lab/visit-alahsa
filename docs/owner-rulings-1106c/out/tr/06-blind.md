# Blind read: terrain-map intro (tr)
## 1) What the page offers and what to do
This is a relief (terrain) map of the Al-Ahsa oasis, showing Jebel Qara, the palm groves and the dunes to the east. Every place worth visiting is marked on the map where it is located. To make a place appear on the map, I press the small icon button next to its name in the list (tooltip "Haritada gösterin"). To open a place's own page, I select/click its name. Yes, it is clear which thing to press for each: button = show on map, name = open page. The only small gap is that the button is an icon, so I rely on the tooltip to know what it does.

## 2) Stumbles
1. "Kabartma harita": I first understood "embossed/raised-relief map", which fits a terrain map, but it is slightly technical; "Arazi haritası" or "Rölyef haritası" might be more everyday. Minor.
2. "Gezi rehberiKabartma harita": the breadcrumb and the title run together with no separator (probably two elements), so it reads as one odd word. Probably a cut artifact, but worth noting.
3. "Kabartma haritada vaha: Cebel el-Kare, hurmalıklar ve doğu tarafındaki kumullar.": it is a fragment without a verb. I first read it as "the oasis on the relief map is: Jebel Qara, palm groves and dunes", and I was not sure whether it describes what is drawn or lists what I can find. Understandable but a bit telegraphic.
4. "doğu tarafındaki kumullar": "dunes on the eastern side" is fine; "doğusundaki" would be a little more natural. Very minor.
5. "bulundukları noktada işaretlidir": understandable, slightly stiff and bureaucratic ("yerlerinde işaretlidir" would be lighter).
6. "adının yanındaki düğmeye basın": clear, but "düğme" is an icon, so I looked for a labelled button. The tooltip "Haritada gösterin" uses a formal "-in" command form; fine.
7. "sayfasını açmak için ise adını seçin": "seçin" (select) is slightly ambiguous; I assumed "tıklayın". Also "ise" makes the contrast clear, which helps.

## 3) Readability of the two intro lines
82/100: Clear and mostly natural Turkish that tells me exactly which control does what, with only a telegraphic first sentence and some slightly stiff phrasing.
