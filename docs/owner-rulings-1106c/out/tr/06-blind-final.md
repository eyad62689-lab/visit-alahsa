# Fresh read on final: terrain-map instruction (tr)
## 1) What to do
To see a place on the map, I press the small icon button next to its name in the list. To open its page, I press the name itself. On a phone I can find both: the icon button sits right beside each name (I would press the small icon left of "Beyt el-Biat", for example), and the name is plain tappable text. I would not know from the icon alone that it means "show on map", since the tooltip does not appear before pressing, but the instruction line tells me it is the button next to the name, so I would try it. For opening the page I would tap the name "Beyt el-Biat".
## 2) Stumbles
1. "listede adının yanındaki düğmeye" - I first understood only "a button beside the name" without knowing what the button looks like; on a phone with several elements it is not stated that it is an icon, but in a list where each name has just one button next to it, it is guessable. Minor.
2. "haritada görmek" - slightly unclear whether the map scrolls or zooms to the place or only highlights it, but the meaning is clear enough.
3. "adına basın" - natural, but I briefly wondered whether pressing the name might also do something to the map; the contrast "ise" settles it.
Otherwise none; the wording is natural Turkish.

88/100 - Natural, short, clear two-part instruction; only the unspecified look of the button keeps it from higher.
