# Blind read: terrain-map intro (ur)
## 1) What the page offers and what to do
This is a relief/terrain map of the Al-Ahsa oasis showing Jabal al-Qarah, date palm groves, sand dunes in the east, and every tourist site in its place. Below the map is a list of all sites grouped by category (e.g. historical sites). To make a place appear on the map, I press the small icon button next to its name in the list (tooltip "show on map"). To open a place's own page, I press the name itself. This is fairly clear: the button is by the name and the name is the link. The only small uncertainty is that the intro says "the button next to the name" while the buttons are only icons, so I rely on the tooltip to know which one it is.
## 2) Stumbles
1. "سیاحتی معلوماتزمین کے نشیب و فراز کا نقشہ": the label "سیاحتی معلومات" runs straight into the title with no space, so it reads as one word (probably a breadcrumb/eyebrow stuck to the heading). Not part of the two intro lines proper, but confusing.
2. "نشیب و فراز": I understood "ups and downs", which is natural Urdu for uneven ground, but it is slightly figurative for a terrain map; "زمین کی ساخت/ابھار" would be more technical. Minor.
3. "نخلستان کی زمین اپنے نشیب و فراز کے ساتھ": a bit stiff, as if translated ("the oasis's land with its ups and downs"); the sentence has no verb, which is fine as a caption.
4. "جبل القارہ": an Arabic-style name in Urdu spelling; readable, but I would normally expect "جبلِ قارہ". Minor.
5. "اسے نقشے پر دیکھیں" in line 2: "اسے" is ambiguous at first (the name or the button?), though context resolves it to the place. "نام کو چن کر": "چن کر" (choose) is slightly unusual for clicking/tapping; "دبا کر" or "پر کلک کر کے" would be more natural.
6. "بٹن کو چن کر" has the same wording; the button is an icon, not text, so "ساتھ والے بٹن" is understood only after seeing the icon.
## 3) Readability of the two intro lines
80/100: clear and understandable with an accurate instruction, but slightly stiff, translation-like phrasing ("چن کر") and a run-together label above them.
