## Icons
The PWA icons reuse the site's own `icon-192.png`, `icon-512.png` and `maskable-512.png` (the bulbul icon, generated by `tools/gen-site-icons.mjs`).

## Sound
There are no audio files. All five cues are synthesised in code with the Web Audio API (oscillators and envelopes) and are original to this project.

## Fonts and colours
These are the site's self-hosted fonts and `tokens.css`. Nothing new is added.

## Text
- **Landmark facts:** the attraction `summary` / `summary_en`, verbatim, read at build time.
- **Interface strings:** written for this game, in ar and en.
