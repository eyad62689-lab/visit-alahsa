# تقارير حماية المحتوى الأسبوعية

هذا المجلد يستقبل تقارير المسح الأسبوعي (Markdown) التي تولّدها دالة
`theft-scan` المجدولة كل يوم اثنين.

التقارير تُكتب أولاً في Netlify Blobs (الدالة المجدولة لا تستطيع الكتابة في
المستودع مباشرة)، وتُسحب إلى هنا بالأمر:

```bash
NETLIFY_SITE_ID=... NETLIFY_AUTH_TOKEN=... npm run pull:reports
```

- ما يحويه كل تقرير وكيف تتصرف عند رصد سرقة: راجع
  [docs/content-protection.md](../docs/content-protection.md).
- عند اكتشاف تطابق خارجي يصلك أيضاً تنبيه بالبريد فوراً (إن كانت مفاتيح
  Resend مضبوطة في لوحة Netlify) — دون انتظار سحب التقرير.
